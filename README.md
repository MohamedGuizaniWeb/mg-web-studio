# MG Web Studio Portfolio

A responsive one-page portfolio website for MG Web Studio.

## Before publishing

1. Open `index.html` and replace:
   - `YOUR_EMAIL@gmail.com`
   - `+1 (514) 000-0000`
2. Open `script.js` and replace:
   - `YOUR_EMAIL@gmail.com`
3. Adjust prices if needed.
4. Add real project links when your demo websites are ready.

## Test locally

Double-click `index.html`, or use the VS Code extension **Live Server**.

## Files

- `index.html` — page content
- `styles.css` — design and mobile layout
- `script.js` — menu, language switch, form and animations
